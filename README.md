## 三个备选剧本

### 《上线！》→ [`scripts/上线/`](scripts/上线/)
AI简历筛选系统上线前，伦理审查走过场，人人签字合规，出了歧视丑闻后人人甩锅。整改三天，再次上线。
- 风格：讽刺喜剧，循环结尾，台词少，最好拍

### 《删库跑路》→ [`scripts/删库跑路/`](scripts/删库跑路/)
实习生手滑删了生产库，主管选择捂盖子对外谎称系统维护，最终被CTO拆穿。
- 风格：有紧张感和反转，结局相对正向，节奏最好

### 《用户协议》→ [`scripts/用户协议/`](scripts/用户协议/)
App违规收集用户数据一年，解决方案是把条款塞到协议第47页、字号8号、三秒弹窗自动消失。
- 风格：荒诞喜剧，讽刺感最强，结尾留白

## 如何使用这个仓库

1. 读完这个 README，知道整体情况
2. 点进选定剧本的文件夹，读那里的 README，了解剧情和角色
3. 在 casting.md 里填上自己的名字，认领角色
4. 只读自己的 role 文件，知道自己说什么、什么时候说
5. 完整剧本在 script.md，有疑问再查
